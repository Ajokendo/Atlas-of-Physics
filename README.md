# Атлас физики — русская версия

Русскоязычная адаптация интерактивного учебника Atlas of Physics.

Проект основан на открытом исходном коде Nathan Liow: https://github.com/nathanliow/atlas-of-physics

Оригинальный проект распространяется по лицензии MIT. См. файл LICENSE. Авторские уведомления сохраняются.

## Цель
- Русский интерфейс и учебные объяснения.
- Интерактивные 3D-модели движения, сил, полей и графиков.
- Практические задачи с пошаговыми решениями.
- Адаптация для телефонов и планшетов.

## Запуск
Откройте сайт через любой статический сервер, например:
`python3 -m http.server 8137`

Затем перейдите на `http://localhost:8137`.

## Статус
Начальная загрузка исходной структуры и поэтапная локализация. Перевод и проверка глав выполняются последовательно.
