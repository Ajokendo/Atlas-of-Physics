# Атлас физики — русская версия

Русскоязычная адаптация открытого интерактивного учебника Atlas of Physics.

Исходный проект Nathan Liow: https://github.com/nathanliow/atlas-of-physics  
Оригинальный проект распространяется по лицензии MIT. См. файл LICENSE. Авторские уведомления сохраняются.

## Что реализовано

- Русскоязычная главная страница и каталог из 15 глав.
- 15 отдельных учебных страниц: механика, электричество и магнетизм.
- Объяснения основных понятий и законов, формулы и примеры расчётов.
- Интерактивные расчётные модели с настраиваемыми параметрами и вычисляемыми результатами.
- Отдельная WebGL/Three.js 3D-сцена в каждой из 15 глав: модели движения, сил, колебаний, полей, цепей и индукции.
- Живые графики физических величин, формульные расчёты и числовые результаты, пересчитываемые при изменении параметра модели.
- Управление 3D-сценой перетаскиванием, настройка скорости анимации и параметра модели; автоматическая пауза вне экрана.
- Проверочные вопросы с объяснением правильного ответа.
- Адаптивная верстка для смартфонов и компьютеров.
- Отдельная интерактивная лаборатория вертикального броска.

## Запуск локально

Откройте каталог проекта через статический сервер:

```bash
python3 -m http.server 8137
```

Затем перейдите на http://localhost:8137.

## Примечание

Это русскоязычная учебная адаптация с собственными объяснениями, интерактивными расчётными моделями и дополнительными 3D-сценами на Three.js. 3D-сцены являются учебными визуализациями, а не точными инженерными симуляторами. Она не заменяет лабораторное оборудование и не претендует на профессиональное инженерное моделирование. Физические модели используют указанные в главах идеализации и допущения.
