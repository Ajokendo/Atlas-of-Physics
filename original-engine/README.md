# Интеграция оригинального движка

Перенос оригинального движка выполняется по главам. Уже добавлены «Кинематика», «Законы Ньютона» и «Движение по окружности» и «Работа, энергия и мощность» и «Импульс и удар» и «Колебания» и «Вращение».

Исходный проект Nathan Liow: https://github.com/nathanliow/atlas-of-physics
Лицензия MIT и уведомления об авторстве должны сохраняться.

Порядок работ:
1. Подключить оригинальные модули сцены и рендеринга.
2. Перевести интерфейс, подписи и учебные подсказки.
3. Проверить физические инварианты и синтаксис JavaScript.
4. Проверить публикацию на GitHub Pages.
5. Проверить сенсорное управление и производительность на смартфонах.
6. Только после проверки переносить следующие главы.

Пути лабораторий: `kinematics/`, `newton/` и `circular/` и `energy/` и `momentum/` и `oscillations/` и `rotation/`.

Русские главы в корне репозитория остаются основной версией сайта.
