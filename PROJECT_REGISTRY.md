# Atlas of Knowledge — Project Registry

Единый реестр дисциплинарных атласов. Это источник истины для всех ИИ-помощников и участников разработки.

## Обязательное правило для каждого помощника
1. Сначала прочитать этот файл из ветки `atlas-of-knowledge-integration`.
2. Работать только в назначенной дисциплине и её рабочей ветке.
3. Не редактировать другие дисциплины, корневой портал, каталог или общие настройки без отдельного поручения.
4. Не создавать повторно существующие главы и не удалять исходные материалы.
5. Перед началом проверить актуальный HEAD назначенной ветки; перед передачей сообщить изменённые файлы, коммиты и проверки.
6. Не сливать ветки самостоятельно. Все изменения сначала проходят через интеграционную ветку и аудит.
7. Различать наличие файла, редакционную готовность и публикацию.

## Рабочие пространства дисциплин

Каждая рабочая ветка является отдельным потоком разработки внутри одного репозитория. Ветки содержат общий снимок репозитория, поэтому помощник обязан изменять только назначенную папку дисциплины.

| Дисциплина | Рабочая ветка | Папка дисциплины | Стартовая страница |
|---|---|---|---|
| Physics / Физика | `workspace/physics` | корень проекта, `chapters/`, `original-engine/` | `index.html` |
| Chemistry / Химия | `workspace/chemistry` | `chemistry/` | `chemistry/index.html` |
| Biology / Биология | `workspace/biology` | `biology/` | `biology/index.html` |
| Geography / География | `workspace/geography` | `geography/` | `geography/index.html` |

### Границы ответственности
- Physics: только физические материалы в корне, `chapters/` и `original-engine/`.
- Chemistry: только `chemistry/`.
- Biology: только `biology/`.
- Geography: только `geography/`.
- Общие файлы (`portal.html`, `catalog.html`, корневой `README.md`, `PROJECT_REGISTRY.md`, общие CSS/JS и настройки публикации) принадлежат центральной интеграции. Изменять их можно только по отдельному поручению координатора.

## Статусы и ограничения аудита
- **File inventory** — число файлов, проверяемое по Git tree.
- **Editorial status** — степень научной, методической и языковой готовности; требует отдельной проверки содержания.
- **Published status** — доступность на GitHub Pages; требует проверки Pages и маршрутов.
- Для Biology, Chemistry и Physics наличие глав не означает, что каждая глава прошла финальную научную и редакционную проверку.
- Для Geography обнаружены 25 файлов глав 02–26. Файл главы 01 не обнаружен в проверенной папке; требуется поиск в истории/других ветках.
- Географические Markdown-материалы перенесены из `portal-foundation` в интеграционную ветку без изменения содержимого. Полноценную веб-навигацию и рендеринг глав ещё нужно проверить.
- Каталог `catalog.html` требует расширения до четырёх дисциплин.
- Ветки `workspace/*` — рабочие ветки, не отдельные репозитории и не опубликованные самостоятельные сайты.

## Процесс передачи изменений
1. Помощник работает в своей `workspace/<discipline>` ветке и только в разрешённой папке.
2. По завершении сообщает краткий отчёт: что изменено, список файлов, commit SHA, проверки и известные проблемы.
3. Координатор проверяет изменения и переносит их в `atlas-of-knowledge-integration`.
4. После общего аудита интеграция может быть предложена к слиянию в `main`.
5. Не удалять старые исходные ветки: они сохраняются как источники и резервные контрольные точки.
