# Atlas of Knowledge — Project Registry

Единый реестр дисциплинарных атласов. Это источник истины для всех ИИ-помощников и участников разработки.

## Правило продолжения работы
1. Перед началом работы прочитать этот файл из основной интеграционной ветки.
2. Сверить указанные пути и ветки с фактическим Git tree.
3. Различать **наличие файла**, **редакционную готовность** и **публикацию**. Одно не доказывает другое.
4. Не создавать повторно существующие главы.
5. После изменения проекта обновлять этот реестр отдельным коммитом с фактическими SHA и результатами проверок.
6. Не считать рабочую ветку основной до успешного аудита, CI и слияния.

## Статусы и ограничения аудита
- **File inventory** — число файлов, проверяемое по Git tree.
- **Editorial status** — степень научной, методической и языковой готовности; требует отдельной проверки содержания.
- **Published status** — доступность на GitHub Pages; требует проверки Pages и маршрутов.
- Для Biology, Chemistry и Physics наличие глав не означает, что каждая глава прошла финальную научную и редакционную проверку.
- Для Geography обнаружены 25 файлов глав 02–26. Файл главы 01 не обнаружен в проверенной папке; требуется поиск в истории/других ветках. Наличие Markdown-файлов не означает наличие готового веб-атласа.
- Geography была обнаружена в ветке `portal-foundation`; материалы перенесены без изменения содержимого в интеграционную ветку.
- Chemistry проверена в `main` и `chemistry-atlas-integration`; в `main` уже присутствуют 11 глав и расширенные вспомогательные страницы.
- Biology проверена в `main`; 12 глав обнаружены в `biology/chapters/`.
