# Atlas of Chemistry — Атлас химии

Самостоятельный дисциплинарный атлас в составе **Atlas of Knowledge**.

- Платформа: https://github.com/Ajokendo/Atlas-of-Knowledge
- Рабочая ветка: `workspace/chemistry`
- Папка дисциплины: `chemistry/`
- Главная страница: `index.html` (относительно этой папки)
- Публикационный адрес после интеграции: https://ajokendo.github.io/Atlas-of-Knowledge/chemistry/

## Концепция

Атлас объясняет химию как науку о составе, строении, свойствах и превращениях вещества. Учебный маршрут построен от микромира атомов к веществам, реакциям, органическим соединениям и химии жизни.

Визуальная идентичность дисциплины: изумрудный и зелёный акценты, бирюзовые интерактивные элементы, светлая нейтральная основа. Интерфейс рассчитан на широкие и мобильные экраны. Основная навигация и учебные материалы поддерживают русский и английский языки там, где это реализовано в соответствующей странице.

## Учебная структура

| № | Тема | Основной материал |
|---|---|---|
| 01 | Строение атома | Протоны, нейтроны, электроны, электронные оболочки |
| 02 | Химические элементы | Изотопы, относительная атомная масса, символы |
| 03 | Периодическая система | Группы, периоды, периодические свойства |
| 04 | Химическая связь | Ионная, ковалентная и металлическая связь |
| 05 | Количество вещества | Моль, постоянная Авогадро, молярная масса |
| 06 | Химические формулы | Состав соединений и расчёты |
| 07 | Растворы | Растворимость и концентрация |
| 08 | Кислоты и основания | pH, индикаторы, нейтрализация, соли |
| 09 | Химические реакции | Типы реакций и уравнивание уравнений |
| 10 | Окислительно-восстановительные реакции | Степени окисления и электронный баланс |
| 11 | Органическая химия | Углеводороды и основные классы органических соединений |

Главы расположены в `chapters/`. Сейчас это 11 отдельных HTML-страниц; тема № 03 («Периодическая система») реализована отдельной интерактивной страницей `periodic-table.html`, поэтому учебный маршрут включает все 12 тем. Отдельные темы дополнены интерактивными страницами и справочниками.

## Интерактивные инструменты и справочные материалы

- `periodic-table.html` — интерактивная периодическая таблица.
- `molecule-lab.html` — визуальная лаборатория молекул.
- `virtual-lab.html` — виртуальные химические эксперименты.
- `reaction-trainer.html` — тренажёр уравнивания реакций.
- `stoichiometry.html` — расчёты по стехиометрии.
- `gas-laws.html` — интерактивное изучение газовых законов.
- `chemistry-constants.html` — физические и химические константы.
- `glossary.html` — химический глоссарий.
- `knowledge-check.html` — проверка знаний.

## Структура папки

- `index.html` — главная страница и карта учебного маршрута.
- `chapters/` — 11 отдельных HTML-страниц глав; тема № 03 представлена интерактивной периодической таблицей.
- `assets/` — SVG-иллюстрации и схемы.
- Остальные HTML-файлы — интерактивные лаборатории, тренажёры и справочники.
- `checks.mjs` — проверка HTML-страниц, локальных ссылок, ресурсов и встроенного JavaScript.
- `browser-smoke.mjs` — браузерные smoke-тесты основных страниц и взаимодействий.

## Локальная проверка

Из корня репозитория:

```bash
node chemistry/checks.mjs
npm install --no-save playwright
npx playwright install --with-deps chromium
python3 -m http.server 4173 --bind 127.0.0.1
```

Во втором терминале:

```bash
node chemistry/browser-smoke.mjs
```

Проверки следует запускать после изменений и фиксировать результат в отчёте по рабочей ветке. Наличие автоматических тестов само по себе не означает, что они успешно пройдены в текущем коммите.

## Правила разработки

1. Изменять в этой рабочей ветке только папку `chemistry/`.
2. Сохранять существующие материалы и историю; перед заменой файла сравнивать версии.
3. Проверять научную точность, размерности, единицы СИ, химическую нотацию, баланс атомов и зарядов в уравнениях.
4. Для расчётных инструментов показывать формулу, единицы, ход вычисления и ограничения применимости.
5. Для интерактивов предусматривать клавиатурное управление, понятные подписи и мобильный интерфейс.
6. Не объявлять главу завершённой без научной и методической проверки.
7. Не изменять общий портал, каталог, корневые файлы или другие дисциплины: ими занимается центральная интеграция.
